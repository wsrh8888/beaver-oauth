## ✨ Core Features

- 🔐 **OAuth Code Login** - Integrates with the open platform for desktop client authorization
- 📱 **QR Scan Confirmation** - Mobile scan to confirm desktop login
- 🔗 **SDK Integration** - Works with `@beaver-im/js-sdk`
- 🎨 **Modern UI** - Clean authorization pages based on Element Plus
- ⚡ **Lightweight** - Focused on auth flow only

## 🚀 Quick Start

### Environment Requirements
- Node.js >= 18.0.0

### Installation Steps
```bash
# Clone the project
git clone https://github.com/wsrh8888/beaver-oauth.git
cd beaver-oauth

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build_prod

# Build for testing
npm run build_test
```

Development server: http://localhost:8045

### Environment Configuration
1. Create `.env.development` (development)
2. Create `.env.test` (testing)
3. Create `.env.production` (production)
