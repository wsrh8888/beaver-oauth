# Beaver Manager 界面截图

## 📊 截图文件说明

### 🔄 版本管理模块 (Version Management)
- `version-list.png` - 版本列表页面，展示所有应用版本信息
- `architecture-management.png` - 架构管理页面，不同平台的架构配置
- `app-management.png` - 应用管理页面，应用的基本信息管理

### 😀 表情包管理模块 (Emoji Management)
- `emoji-collections.png` - 表情包合集管理页面，表情包分类和合集管理
- `emoji-management.png` - 表情包管理页面，单个表情包的编辑和管理
- `emoji-list.png` - 表情列表页面，表情的列表展示和搜索
